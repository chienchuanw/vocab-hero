### Behavior

**Development Mode:**
- Update checks are skipped
- Console logs: "[updater] Skipping auto-update in development mode"

**Production Mode:**
- Checks for updates 5 seconds after app startup
- If update available: Shows dialog with "Download" / "Later" buttons
- If user clicks "Download": Downloads update in background
- When download complete: Shows dialog with "Restart" / "Later" buttons
- If user clicks "Restart": Quits and installs update
- If user clicks "Later": Update installs on next app quit

### GitHub Release Requirements

For auto-update to work, GitHub releases must include:
- macOS: `.dmg` or `.zip` files
- Release must be published (not draft)
- Release must include `latest.yml` metadata file (generated by electron-builder)

### Next Steps

When ready to publish a release:
1. Update version in `packages/desktop/package.json`
2. Run `pnpm electron:build` to create distributable
3. Create GitHub release with generated files from `packages/desktop/release/`
4. electron-builder will automatically generate and upload `latest.yml`
