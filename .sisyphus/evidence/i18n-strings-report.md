## Notes

1. **Chinese Strings**: Quality rating buttons contain Chinese labels (完全忘記, 不太確定, etc.) that should be kept as-is or mapped to appropriate translations
2. **Dynamic Content**: Many strings contain placeholders like `{word}`, `{group}`, `{count}` that need proper i18n interpolation
3. **Pluralization**: Several strings need plural forms (e.g., "item" vs "items", "word" vs "words")
4. **Loading States**: Most action buttons have corresponding loading states (e.g., "Adding..." for "Add")
5. **Validation Messages**: Form validation errors are inline strings that need translation
6. **Empty States**: Several components have empty state messages
7. **Accessibility**: Some strings are used in aria-labels and should be translated for screen readers

## Recommendations

1. **Priority 1 (High Visibility)**: nav, common buttons, page titles
2. **Priority 2 (User Actions)**: vocabulary, groups, study modes
3. **Priority 3 (Settings & Advanced)**: settings, progress, quiz
4. **Priority 4 (Edge Cases)**: errors, empty states, validation messages
