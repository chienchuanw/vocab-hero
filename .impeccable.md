# Vocab Hero — Design Context

## Users

**Primary audience**: Self-study hobbyists learning Japanese casually — motivated by anime, manga, travel, or general curiosity. They are not preparing for exams under pressure; they want a fun, low-friction tool that makes vocabulary practice feel rewarding rather than tedious.

**Context of use**: Short daily sessions (5-15 minutes), often on mobile. Users open the app when they have a spare moment — commuting, waiting, winding down. They may also use it at a desk alongside Duolingo or other learning resources.

**Job to be done**: Build and retain Japanese vocabulary through spaced repetition, with enough variety (flashcards, quizzes, matching, spelling, listening) to keep practice from feeling monotonous. Import vocabulary from Duolingo screenshots to bridge the two tools.

## Brand Personality

**Three words**: Fun, Encouraging, Playful

**Voice & tone**: Warm and upbeat without being childish. Celebrate progress enthusiastically (confetti, streaks, bounce animations) but never patronize. Error states should feel supportive ("Try again!") not punitive. The app should feel like a cheerful study buddy, not a strict teacher.

**Emotional goal**: Playful curiosity — every session should spark a "what's next?" feeling. The interface should make users want to tap one more card, try one more quiz.

## Aesthetic Direction

**Visual tone**: Duolingo-inspired with Anki's depth. Bright, clean, rounded, and gamified on the surface — but backed by serious SRS mechanics under the hood. The UI should feel approachable and alive, never clinical or overwhelming.

**Primary reference**: [Duolingo](https://www.duolingo.com/) — gamified learning, bold green primary, physical-feeling buttons with push-down shadows, celebration moments, streak motivation, bottom tab navigation, mobile-first layout.

**Secondary reference**: [Anki](https://apps.ankiweb.net/) — power-user SRS depth, rating-based review (0-5 scale), spaced repetition scheduling. Vocab Hero borrows Anki's learning engine but wraps it in Duolingo's approachable skin.

**Anti-references**:
- Boring dictionary apps — no clinical, text-heavy, utilitarian layouts. The app must feel alive with color, motion, and personality.
- Complex/overwhelming UIs — no dense dashboards, settings overload, or power-user complexity on the surface. Advanced features (SRS intervals, mastery levels) should be discoverable but not in-your-face.

**Theme**: Both light and dark mode, fully implemented. Light mode uses a soft blue-gray background with white cards; dark mode uses deep blue-gray tones. Both maintain the signature Duolingo green as primary.

## Design Principles

### 1. Reward Every Interaction
Every tap, swipe, and answer should feel satisfying. Use micro-animations (bounce, shake, confetti), progress indicators, and streaks to create a sense of momentum. Learning is a grind — the UI's job is to make it feel like play.

### 2. Simplicity Over Features
Show only what's needed for the current task. Study modes, vocabulary management, and progress tracking each get their own focused screen. Complexity lives in the data model, not the interface. When in doubt, remove.

### 3. Mobile-First, Always
The primary experience is a phone held in one hand. Bottom navigation, large touch targets, thumb-friendly layouts. Desktop is a nice-to-have, not the design driver. Every component should work beautifully at 375px before scaling up.

### 4. Consistent Visual Language
Use the established design tokens religiously — Duolingo green primary, oklch color space, 1rem base radius, Geist font family, shadcn/ui new-york components. Deviations from the token system require justification.

### 5. Accessible by Default
WCAG 2.1 AA compliance is the baseline, not an afterthought. Primary green is already darkened for 4.5:1 contrast. All interactive elements must be keyboard-navigable. Animations must respect `prefers-reduced-motion`. Color alone must never be the only indicator of state.

### Typography
- **Sans**: Geist Sans (`--font-geist-sans`)
- **Mono**: Geist Mono (`--font-geist-mono`)
- **Features**: `rlig`, `calt` enabled

### Spacing & Radius
- **Base radius**: `1rem` (intentionally rounded, Duolingo-style)
- **Radius scale**: `sm` (-4px), `md` (-2px), `lg` (base), `xl` (+4px), `2xl` (+8px), `3xl` (+12px), `4xl` (+16px)
- **Max content width**: `max-w-screen-xl`
- **Page padding**: `px-4 py-6`

### Animations
- **Button press**: `translateY(2px)` + shadow reduction on `:active`
- **Card hover**: `translateY(-2px)` + shadow increase, 0.2s ease
- **Success**: scale bounce (1 → 1.1 → 1), 0.3s
- **Error**: horizontal shake (-10px → 10px), 0.4s
- **Progress bar**: width transition, 0.3s ease
- **Page transitions**: framer-motion
- **Celebrations**: canvas-confetti

### Component Library
- **Base**: shadcn/ui (new-york style, neutral base)
- **Installed**: alert-dialog, avatar, badge, button, card, dialog, dropdown-menu, input, label, popover, progress, select, sheet, skeleton, slider, sonner (toasts), switch, tabs, textarea, tooltip
- **Icons**: lucide-react
- **Charts**: recharts
